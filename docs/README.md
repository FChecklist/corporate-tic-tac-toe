# Docs: Corporate Tic Tac Toe

Written for a non-technical owner. Short plain sentences. The site is live on Cloudflare Pages (in TEST mode until real payments are switched on); every change is tested locally first, and what is live is recorded in `DEPLOYS.md`.

## The game
- `RULES.md`: the rules, R01 to R37, one sentence each, each with a test.
- `GAME.md`: where the game lives in the code, and which page is which.
- `PROTOTYPE_NOTES.md`: the earlier three-board prototype (kept for reference, not used).

## Running it
- `RUNNING.md`: how to run the tests and the local server.
- `TEST_AND_LIVE_MODE.md`: the TEST and LIVE switch for e-mail and payments.

## People and data
- `PRIVACY_AND_LIFECYCLE.md`: the data map (every field, why, where, who, how long), the player notice, the deletion clock.
- `RETENTION.md`: what is kept and for how long, table by table.
- `BREACH_RUNBOOK.md`: what to do if data leaks, who is told, how fast.
- `WINNERS_AND_AUDIT.md`: how winners are decided, the winners record, the audit log.
- `compliance/DRAFTS_README.md`: the legal pages.

## Roles, console and AI
- `ROLES_AND_CONSOLE_SPEC.md` to `ROLES_AND_CONSOLE_SPEC_6.md`: Organizer, Host, Co-host; people and links; cancel and credit; clone. Build specs, read in order.
- `AI_LINK.md`: the short AI work link.
- `AI_WORK_PROMPT_ORGANIZER.md`: what an AI helper may and may not do for an organizer.

## Words, brand, cases
- `GLOSSARY.md`: the words we use and the words we never use.
- `BRANDING.md`: name, colours, e-mail header and footer.
- `USE_CASES.md`: tournament use cases and what should happen.

Where a document and the code disagree, the code is right, and the document has a "Not true yet" line saying so.
