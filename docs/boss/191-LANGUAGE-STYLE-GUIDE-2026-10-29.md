# Language style guide for organizer / host / co-host screens (all games, DPDP-style products too). Owner rules 29 Oct 2026.
Audience: an HR person who is afraid to give details and must never be confused. Warm, short, plain English, correct grammar.
1. Say "the system", never "we". 2. Never "invite/invited" (use "game link", "join", "your people", "bring people"). 3. Never "private" (say "close group"). 4. Say "participants" (not "places", not "seats"). 5. "in any location" / "wherever they are": never "in the office". 6. Money: ₹ sign, never "Rs"; prizes are gifts, never cash. 7. Speak TO the organizer ("you"): lead with what the system does for them and what is deleted, then what they must do ("you can add..." not "you must upload"). 8. Buttons are verbs and short ("Pay now", "Let in", "Not now", "Copy link"). 9. Reassure first ("Don't worry...") when something is pending. 10. Tags: (Popular) before (Recommended). 11. One idea per sentence; explain every role: Host = right hand, any change like the organizer, max 5; Co-host = brings people, cannot change the game, unlimited. 12. Claims must be TRUE in code (check before live): deletion within 24 hours, no email to participants, passcode email only to Host/Co-host. 13. Cialdini used honestly: defaults filled first (reciprocity), visible progress (commitment), "Most organizers pick this" only with real data, plain safeguards (authority), warm words (liking), only real time facts (no fake scarcity). 14. Terms: Game dashboard, Game link, Waiting for you, Tickets claimed, Game board, System validates for you, You validate yourself, Brand & Breaks, Message break, Super Bumper House 1-10, 1st-5th Full House.
