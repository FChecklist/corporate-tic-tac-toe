How Corporate Tic Tac Toe plays

A match is three boards. The player with the most points over all three wins.

The boards

Board 1: 3x3

The classic board. 9 squares.

Board 2: 4x4

16 squares.

Board 3: 5x5

25 squares.

Each board is played until it is full. X moves first. Who plays X is a random draw each board: a fresh draw for board 1, the other player on board 2, and a fresh draw for board 3.

How points are scored

A run is an unbroken stretch of your marks along a row, a column or a diagonal. Only the longest unbroken stretch counts. A run of 4 is worth a 4, not also a 3 and a 2.

Example, 3x3 board: X has a vertical run of 3 (10), a horizontal run of 2 (1) and a diagonal run of 2 (3). X scores 14.

  • 3x3 uses runs of 2 and 3. 4x4 uses 2 to 4. 5x5 uses 2 to 5.
  • The player who moves second gets a small bonus on each board, because the first player gets the first move.
  • You have 8 seconds a move. If time runs out a move is placed for you at random.

The tournament

1

Everyone is paired at random

A public random draw pairs all players. With an odd number, one gets a bye. Nobody gets two.

2

Winners advance

Each round halves the field.

3

Repeat to the final

1,000 players need 10 rounds.

4

The champion

The last player standing wins.

Clear winners

If two players have the same total, the next measure decides: the most valuable single run, then the points on the last board. The last measure is a random draw from public data that anyone can re-check. Every tournament shows a clear 1st to 5th and a top-ten list.

No server in the game

Moves are signed on each device and sent straight to the opponent. Both devices keep the same record, and anyone can re-play it to get the same score. Our server only helps two devices find each other and records the result.
